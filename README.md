# Telecom Customer Churn Analysis

An end-to-end look at why telecom customers leave, built around data-quality checks, SQL analysis, and Power BI reporting.

## What this project does

The analysis uses customer-level telecom data to explore:

- how many customers have churned
- which customer groups are most likely to leave
- whether pricing, contract type, services, or support issues are linked to churn
- where the source data needs to be cleaned or validated before reporting

The goal is to turn the raw customer data into clear, useful findings that could support customer-retention decisions.

## Repository layout

Folder Contents ;
